# Casa do Tatu

Festas que contam histórias. Projeto de site para Casa do Tatu — serviço de festas autorais para infância.

## Sobre

Site responsivo com navegação mobile elegante, hero com background customizado e seção "Sobre quem cria" com design em card.

## Estrutura

- `casa-do-tatu.html` — Marcação semântica e acessível
- `casa-do-tatu.css` — Estilos responsivos com design system
- `casa-do-tatu.js` — Menu mobile funcional
- `img/` — Imagens do projeto

## Como usar

1. Clone o repositório
2. Abra `casa-do-tatu.html` no navegador

## Responsividade

- Mobile-first
- Menu hamburguer em telas até 900px
- Navegação horizontal em desktop

## Tecnologias

- HTML5 semântico
- CSS3 (Grid, Flexbox, variáveis CSS)
- JavaScript vanilla
